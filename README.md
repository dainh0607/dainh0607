### ⚡ Giới thiệu (About Me)

- 🔭 **Hiện tại:** Tác giả & Kiến trúc sư hệ thống của **[NexaHR ERP](https://github.com/dainh0607/QuanLyNhanSu-HRM)** — Nền tảng SaaS quản trị nhân sự tổng thể, phân ca sản xuất thông minh 24/7 (mô hình 3 ca 4 kíp) và tính toán công - lương tự động theo Luật Lao động Việt Nam.
- 💡 **Thế mạnh cốt lõi:**
  - **Backend Systems:** Thiết kế và phát triển Web API hiệu năng cao bằng **.NET 10 (C#)**, Clean Architecture, SQL Server Row-Level Security (RLS), Redis Distributed Lock, MinIO S3 Object Storage và tích hợp máy chấm công phần cứng thực tế.
  - **Frontend & Mobile:** Xây dựng hệ sinh thái Monorepo đa ứng dụng với **React 19**, **Next.js 16 (Turbopack)** và **React Native (Expo)**.
  - **Văn hóa chất lượng (Quality-First Culture):** Thực thi triệt để Test-Driven Development với **5.200+ Automated Tests** (4.890+ xUnit Tests và 310+ Playwright UI E2E Scenarios) đạt tỷ lệ Pass 100%.
  - **DevOps & Cloud:** Vận hành hạ tầng Docker, Kubernetes, NGINX Reverse Proxy / Load Balancer, Prometheus/Grafana và đường ống CI/CD tự động bằng GitHub Actions.
